# IEEE 1500 wrapper

An IEEE 1500 wrapper and its wrapper serial port (WSP), as a model, as ICL, as PDL and as an
integrity program. See [IEEE 1500 wrappers](../guide/ieee1500-wrapper.md) for how the pieces
fit.

```python
from warptap import (
    Wrapper1500, WbrCell, build_wsp_integrity_program, check_wsp_integrity,
    replay_wsp_program, to_icl_1500, import_icl_1500,
)

wrapper = Wrapper1500(
    name="blk",
    chains=((WbrCell("a", "input"), WbrCell("b", "input")), (WbrCell("y", "output"),)),
)
icl = to_icl_1500(wrapper)                    # ICL the vendored parser accepts
assert import_icl_1500(icl) == wrapper        # warptap's own shape reads back exactly

program = build_wsp_integrity_program(wrapper)
observed = replay_wsp_program(program, wrapper)         # or the values your harness measured
assert check_wsp_integrity(program, observed) == []     # (step, point) pairs that differ

program_json = program.to_json()              # a warptap-wsp-program file, for a tool without warptap
```
